# Задачи 0.1.46 / Tasks 0.1.46

Локальная предварительная сборка **0.1.46, сборка 47**. Включает [изменения 0.1.45](v0.1.45.md).

## Выделение текста и фокус

- В заголовке и описании выделение сворачивается только при фактической потере клавиатурного фокуса. Точка ввода остаётся у конца выделенного фрагмента; уже установленная позиция без выделения сохраняется.
- Отдельного сброса при смене задачи нет. При закрытии активного редактора срабатывает обычный уход фокуса.
- Обычные обновления текста и внутреннее переподключение того же редактора сохраняют его состояние. Undo/Redo остаётся у документа.
- После перехода фокуса обновляется отображение вставки, чтобы в прежнем поле не оставался нарисованный мигающий курсор. Отложенная перерисовка проверяет, что редактор не получил фокус снова.
- Поведение выделения подзадач не изменено.

## Большие кнопки карточки

- Исправлены неработающие нажатия «На сегодня» и «Выполнено» над редактором. Используется штатный стиль borderless, декоративная рамка не перехватывает события мыши.
- UI-тест проверяет включение и выключение обеих кнопок при активном редакторе, нажатия по центру и свободным краям, синхронизацию звезды и выполнения в строке списка и сохранение открытой карточки.

## Проверка

Успешно выполнены **10 тестов редактора и 5 UI-тестов**:

- Переход из заголовка и описания в другой редактор: проверены реальный `firstResponder`, снятие выделения, сохранение позиции без выделения, текста и Undo/Redo. Два сценария параметризованы для обоих полей.
- Закрытие сфокусированного редактора и повторное подключение. Несфокусированный редактор не получает отдельного сброса выделения.
- Прежние проверки кэша, переподключения, истории отмены, независимости документов и измерения многострочного текста.
- UI-сценарии ввода в середине заголовка и описания после ухода фокуса и возврата к задаче, а также два регрессионных сценария курсора в короткой и многострочной подзадаче.
- Отдельный UI-сценарий больших кнопок «На сегодня» и «Выполнено» в карточке задачи.

После исправления перерисовки повторно прошли все 10 тестов редактора и оба UI-сценария заголовка/описания. Снимки тестового окна проверены: в неактивных полях нет прежнего выделения и оставшегося курсора.

Проверки использовали отдельный Bundle ID, отдельную библиотеку с вымышленными данными и подмену календаря. Полный набор тестов не запускался. Общая схема по-прежнему отключает UI-тесты по умолчанию.

## English

Local preview **0.1.46, build 47**. Title and description selections collapse only when keyboard focus actually leaves the editor. The insertion position and document Undo/Redo are retained. Task changes do not apply a separate selection reset, and ordinary updates or internal reattachment preserve editing state. Inactive insertion-point rendering is refreshed after the focus transition.

The large Today and Completed buttons now use the native borderless style, and the decorative outline does not intercept clicks. A UI test verifies both toggle directions, clicks on the center and free edges, list-row state and retention of the open task while editing.

**Verified:** 10 editor tests and 5 UI tests passed. After the redraw adjustment, all editor tests and both title/description UI scenarios passed again, with screenshots inspected. The large-action-button scenario passed after its fix. Tests use an isolated library and fake calendar; the full suite was not run. Universal macOS 26+ ad-hoc signed package; no public release was published.
