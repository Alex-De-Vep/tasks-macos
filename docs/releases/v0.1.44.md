# Задачи 0.1.44 / Tasks 0.1.44

Локальная предварительная сборка **0.1.44, сборка 45**. Включает [изменения 0.1.43](v0.1.43.md).

## Подзадачи

- Названия подзадач переносятся по ширине редактора и автоматически растут по высоте без ограничения количества строк. Длинный текст полностью отображается также после повторного открытия и выполнения пункта.
- Значки выполнения и удаления выровнены по верхней части многострочного пункта.
- Исправлен неработающий клик нижней кнопки «+ Добавить подзадачу». В изолированном UI-тесте прежняя plain-кнопка не вызывала обработчик даже при нажатии по тексту. Кнопки добавления, выполнения и удаления переведены на штатный стиль borderless; расширенная область нижней кнопки сохранена.
- Enter на заполненном пункте по-прежнему добавляет следующий пункт. Порядок, хранение и модель данных не изменены.

## Проверка

Успешно выполнены **два UI-теста и три проверки хранения**:

- Последовательное добавление второго и третьего пунктов именно нижней кнопкой, включая клик по свободной части строки справа от текста. Проверены количество и текст созданных пунктов.
- Длинное название из нескольких строк: проверены полный текст, рост высоты, отсутствие перекрытия следующим пунктом, добавление через Enter, завершение редактирования и перезапуск приложения. После повторного открытия проверены сохранённые тексты, выполнение длинного пункта и удаление другого пункта. Снимок тестового окна также проверен визуально.
- Проверки `ChecklistTests`: миграция и сохранение после повторного открытия, порядок и независимость состояния подзадач, каскадное удаление только пунктов удаляемой задачи.

UI-проверки использовали отдельный Bundle ID, отдельную библиотеку с вымышленными данными и подмену календаря. Полный набор тестов не запускался. Общая схема по-прежнему отключает UI-тесты по умолчанию.

## English

Local preview **0.1.44, build 45**. Subtask titles now wrap and grow vertically without a line limit. Inline add, completion and delete buttons use the native borderless style to fix missed clicks; the add button retains its full-width hit area. Enter still adds the next subtask.

**Verified:** two actual UI tests and three storage tests passed. Scenarios cover repeated additions through the lower button, long text layout, Enter, relaunch persistence, completion and deletion. UI tests used a separate bundle identifier, isolated fictional data and a fake calendar. The full test suite was not run. Universal macOS 26+ package with an ad-hoc signature; no public release was published.
