# Задачи 0.1.38 / Tasks 0.1.38

- Наведение при переносе больше не подменяет выбранную строку боковой панели. Открытая папка сохраняет системное выделение, а назначение переноса отображается отдельно.
- Убрано принудительное усиление нативной строки, которое вместе с временной заменой выбора вызывало переключение активного оформления между папками.
- Выбранная папка без клавиатурного фокуса сохраняет серую системную подложку; название и значок используют фиолетовый акцент приложения. При фокусе в панели сохраняются фиолетовый фон и белый текст.
- Назначение переноса получает фиолетовую скруглённую подложку, белые название и значок — как при выборе папки в фокусе. Открытая папка без фокуса при этом остаётся серой с фиолетовым акцентом. При уходе мыши или завершении переноса временная подсветка исчезает. Данные и правила переноса не меняются.

Приложение и существующие тестовые исходники собираются без запуска. Ручная проверка: смена фокуса между папками, списком, описанием и поиском; перенос с наведением на несколько папок, отмена и завершение переноса; обе темы и неактивное окно.

## English

Drag previews no longer replace the selected sidebar folder or force native row emphasis. The open folder keeps its selection. Unfocused selected folders use gray backgrounds with purple titles and icons. Drop destinations use purple backgrounds with white contents, matching focused selection. App and existing test sources are compiled without running them. UI validation remains manual.
