# Задачи 0.1.36 / Tasks 0.1.36

- Папка под перетаскиваемой задачей получает то же системное выделение, что и при клике: фиолетовый фон, белые значок и название, светлый счётчик.
- Удалены отдельная рамка и полупрозрачная заливка назначения. Размер и скругления определяет штатная строка боковой панели.
- Подсветка временная: наведение не меняет открытую папку, задачу и клавиатурный фокус. При уходе курсора или завершении переноса возвращается прежнее выделение.
- Логика переноса и хранения данных не меняется. «Все задачи» по-прежнему не принимает перенос.

Приложение и тестовые исходники собираются без запуска. Ручная проверка: переносить задачу между папками в обеих темах, отменять перенос и проверять отсутствие смены открытой папки при наведении.

## English

Drag destinations now use the same native sidebar selection as clicked folders, with an emphasized background and white contents. The separate outline is removed. Drag previews do not change the open folder, selected task or keyboard focus, and the original selection returns when the pointer leaves or the drop finishes. Storage and movement rules are unchanged. App and test sources are compiled without running them; UI verification remains manual.
