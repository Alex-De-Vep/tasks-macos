# Задачи 0.1.33 / Tasks 0.1.33

## Изменения

- У задачи одна основная папка: «Входящие», «На неделе», «Месяц» или пользовательская. Неделя и месяц больше не являются временными фильтрами.
- Новая задача создаётся в выбранной папке. В «Сегодня» — во «Входящих» со звездой; во «Всех задачах» — во «Входящих».
- «Сегодня» показывает отмеченные задачи без смены основной папки. «Все задачи» собирает всю библиотеку по дате создания, новые сверху; выполненные остаются внизу.
- Перенос доступен перетаскиванием на папку, через контекстное меню задачи и меню «…» в шапке. Текущая папка отмечена галочкой. Перетаскивание на «Сегодня» добавляет звезду; повторный перенос её не снимает. «Все задачи» не принимает перенос.
- Счётчик в шапке учитывает только активные результаты текущего поиска.
- При переносе выбранной задачи из открытой папки выбирается соседняя активная задача. Раздел выполненных автоматически не раскрывается.

## Данные и миграция

SwiftData V4 → V5 добавляет основную системную папку. Существующая пользовательская папка имеет приоритет над старой отметкой недели/месяца. Если своей папки нет, прежняя отметка определяет «На неделе» или «Месяц» независимо от давности. Остальные задачи остаются во «Входящих». Миграция выполняется один раз.

Перенос сохраняет идентификатор, дату создания, описание, подзадачи, звезду, выполнение, срок, уведомления и календарные связи. Новые копии задач не создаются.

## Проверка

Приложение и тестовые исходники собраны через `build-for-testing` без запуска тестов и приложения. Добавлены регрессионные проверки миграции, создания, переноса, активного счётчика, выбора соседней задачи, отказа сохранения и локальных ссылок перетаскивания. Ручная проверка интерфейса выполняется пользователем.

Универсальная сборка: Apple Silicon и Intel, macOS 26+. Локальная ad-hoc подпись, без Developer ID и нотариализации Apple.

## English

Tasks now have one primary folder: Inbox, This Week, Month or a custom folder. Today mirrors starred tasks; All Tasks lists the library by creation date. Move tasks by dragging them onto sidebar folders, through the task context menu or the toolbar menu. Dropping onto Today adds a star without moving the task. Header counts include active search results only.

The V4 → V5 migration preserves custom folders first, otherwise converts old week/month markers into permanent folders. Task contents, deadlines, notifications and calendar links are preserved. App and regression test sources were compiled without running the app or tests. The universal build uses an ad-hoc signature and is not notarized.
