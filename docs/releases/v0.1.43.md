# Задачи 0.1.43 / Tasks 0.1.43

Локальная предварительная сборка **0.1.43, сборка 44**, для ручной проверки. Включает [изменения 0.1.42](v0.1.42.md) и следующие исправления:

- При переходе в папку список открывается с начала, включая заголовок первой группы в «Сегодня». Изменения задач и звёздочек внутри открытой папки не пересоздают область прокрутки.
- У нижней кнопки «+ Добавить подзадачу» нажимается вся строка, включая прозрачные отступы; минимальная высота области — 32 pt.
- В сборке сохранены боковые отступы 10 pt у подсветки папки при перетаскивании задачи.

Многострочное отображение названий подзадач пока не изменено. Исправление кликов и начальную позицию списка необходимо проверить в установленном приложении.

## Проверка и установка

Приложение и тестовые исходники собраны через `build-for-testing`; тесты и визуальная проверка для этих исправлений не запускались. Универсальная Release-сборка и DMG проходят проверки архитектур, локализации, иконки, прав, подписи и содержимого смонтированного образа. SHA-256 записывается рядом с DMG.

Требуется macOS 26+. Пакет для Apple Silicon и Intel: `Tasks-0.1.43-macOS-universal.dmg`. Перед заменой приложения завершите предыдущую версию. Сборка использует локальную ad-hoc подпись, без Developer ID и нотариализации Apple. Публикация выпуска не выполнялась.

## English

Local preview **0.1.43, build 44**. Includes 0.1.42 and resets folder lists to the beginning, including the first group heading in Today. Star changes within the open folder retain the same scroll-view identity. The inline “Add Subtask” button now accepts clicks across its full-width, 32 pt minimum-height row. Sidebar drop feedback retains its 10 pt horizontal insets.

Subtask titles remain single-line. App and test sources compile; tests and visual verification of these fixes were not run. The universal macOS 26+ ad-hoc signed package is validated by the release packaging script. No release was published.
