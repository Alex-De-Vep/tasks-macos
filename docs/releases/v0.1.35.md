# Задачи 0.1.35 / Tasks 0.1.35

## Выбор и редактирование

- Текст, свободная область строки и внутренние отступы открывают задачу через единый выбор. Подсветкой по-прежнему управляет системный `List(selection:)`.
- Кнопки звезды и выполнения остаются самостоятельными действиями и не получают родительский обработчик нажатия. Перетаскивание, клавиатурная навигация и Delete сохраняются.
- Нативный текстовый редактор теперь подключается через отдельный контейнер SwiftUI. Закэшированный `NSTextView` сохраняет текст и Undo/Redo, а его действующий контейнер единолично управляет делегатом и привязкой к задаче.
- Отключение старого контейнера не сбрасывает обработчики нового. Отложенный запрос фокуса закрытой карточки отменяется и проверяет владельца перед выполнением.
- Название и описание явно доступны для редактирования и выделения текста. Клик в текст принимает фокус без отдельного режима редактирования. Выполнение задачи не блокирует название, описание и подзадачи.
- Смена папки по-прежнему очищает открытую задачу и сворачивает выполненные; повторного автоматического выбора первой выполненной задачи нет. Схема хранения не меняется.

## Проверка

Подготовлены проверки единственного владельца редактора, отключения старого контейнера, маршрутизации изменений в текущую задачу, сохранения Undo/Redo, геометрии текстового поля и области клика. Пользовательские сценарии покрывают разные точки строки, отдельные кнопки, перенос, перезапуск приложения и редактирование сохранённой и выполненной задачи.

Приложение и тестовые исходники собираются без запуска приложения и тестов. Эти сценарии не считаются пройденными до выполнения; ручную проверку выполняет пользователь. Рекомендуется проверить обе темы, обычное и полноэкранное окно, переносы, положение курсора и возврат к ранее открытой задаче.

Локальный DMG: macOS 26+, Apple Silicon и Intel. Подпись ad-hoc, без Developer ID и нотариализации. Выпуск на GitHub не публикуется.

## English

Task rows now have explicit click areas for text, free space and padding while preserving native list selection, independent action buttons and drag-and-drop. Cached text editors are attached through separate SwiftUI-owned containers with ownership-checked delegates and focus requests. Titles, descriptions and subtasks remain editable in saved and completed tasks. Folder-switch behavior and the storage schema are unchanged.

App and regression test sources are compiled without running the app or tests. UI validation remains manual. The local universal build uses an ad-hoc signature and is not notarized; no GitHub release is published.
