# Задачи 0.1.37 / Tasks 0.1.37

- Открытая задача сохраняет штатное выделение в списке при вводе текста и клике по пустому месту. При переходе фокуса в редактор используется обычное серое выделение macOS.
- Повторный клик по той же задаче заново согласует выбор нативного списка, даже если идентификатор открытой задачи не изменился.
- Согласование выбора не переводит фокус из редактора в список. Отдельная заливка и искусственная рамка не добавляются.
- Уходящая строка после выполнения, удаления, переноса или изменения поиска не восстанавливает устаревший выбор. Переход в другую папку по-прежнему очищает карточку и сворачивает выполненные.
- Хранение данных и логика звезды не меняются.

Подготовлены регрессии с настоящим NSTableView: восстановление после снятия выделения, переход к другой задаче, сохранение неактивного оформления, очистка навигации и уход строки. UI-сценарий проверяет создание, ввод, клик по пустому месту, повторное открытие той же строки и Delete.

Приложение и тестовые исходники собираются без запуска. Ручная проверка интерфейса остаётся за пользователем. Локальный универсальный DMG подписан ad-hoc, без нотариализации; GitHub-релиз не публикуется.

## English

The open task retains its native list selection while editing or clicking empty list space. macOS keeps its normal gray selection when the editor has focus. Clicking the same task again repairs native selection without requiring a different task ID. Selection repair does not steal editor focus or add a separate background. Outgoing rows cannot restore stale selections after completion, deletion, movement or filtering. Folder switches still clear the task and collapse completed items.

App and regression sources are compiled without running the app or tests. UI verification remains manual; the local universal build is ad-hoc signed and is not published to GitHub.
