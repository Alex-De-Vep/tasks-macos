# Задачи 0.1.47 / Tasks 0.1.47

Локальная предварительная сборка **0.1.47, сборка 48**. Включает [изменения 0.1.46](v0.1.46.md).

## Раздел выполненных задач

- Завершение выбранной или другой задачи не раскрывает свёрнутый раздел «Выполненные». Его заголовок и счётчик обновляются, открытая карточка задачи сохраняется.
- Раздел раскрывается по нажатию на заголовок. Если пользователь уже открыл его, завершение следующей задачи оставляет раздел открытым.
- Стрелка вниз переходит из активных задач в выполненные только при уже раскрытом разделе.
- Если раздел опустел и исчез, при следующем появлении он снова свёрнут.
- Устранено автоматическое раскрытие при выборе выполненной задачи: карточка может оставаться открытой независимо от состояния раздела.

## Проверка

Успешно выполнены **4 UI-теста и 4 теста логики списка**. Проверены завершение выбранной и другой задачи через строку, завершение через большую кнопку карточки при активном редакторе, ручное раскрытие и сворачивание, сохранение открытого раздела, стрелка вниз и повторное появление опустевшего раздела. Тесты логики проверяют сохранение выбора при выполнении/восстановлении, переключение папок и папку только с выполненными задачами.
