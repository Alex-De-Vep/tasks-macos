# Задачи 0.1.39 / Tasks 0.1.39

- Плавное появление новых задач и исчезновение удалённых со сдвигом соседних строк за 0,26 секунды. Прокрутка к новой задаче также плавная, а редактор получает фокус сразу. Системная настройка уменьшения движения учитывается.
- Пустая звезда «Сегодня» в строке использует адаптивный основной цвет; отмеченная задача сохраняет жёлтую звезду.
- В активной кнопке «На сегодня» значок звезды жёлтый, текст и подложка сохраняют прежние цвета.

Сборка включает предыдущие изменения 0.1.38. Версия приложения — 0.1.39, номер сборки — 40.

Проверка изменений: приложение и тестовые исходники собраны командой `build-for-testing`; тесты и визуальные сценарии не запускались. Пользователь проверяет интерфейс самостоятельно. Release собирается для Apple Silicon и Intel; скрипт упаковки проверяет иконку, локализованные имена, обе архитектуры, права, локальную подпись и содержимое DMG после монтирования только для чтения.

## English

Smooth task insertion and deletion with neighboring rows moving over 0.26 seconds, animated scrolling to a new task and immediate editor focus. Respects Reduce Motion. Inactive Today stars use the system primary color; active stars stay yellow, including the Today action button. Includes the earlier 0.1.38 changes.

Version 0.1.39, build 40. App and test sources compiled successfully; tests and visual scenarios were not run. The user performs visual verification. Universal macOS build, ad-hoc signed without Apple notarization.
