# Задачи 0.1.40 / Tasks 0.1.40

Исправление обновления списка после сообщения о резком появлении и удалении задач в 0.1.39.

- Анимация 0,26 секунды настроена непосредственно у SwiftData-запроса задач: обновление результатов сохранения получает анимационную транзакцию.
- При создании задачи в начале списка не вызывается принудительная прокрутка к уже видимой строке. Если список прокручен вниз, переход к новой задаче остаётся плавным.
- Автоматический выбор соседа после удаления больше не запускает прокрутку поверх удаления — и в активных, и в выполненных задачах.
- Системное уменьшение движения отключает анимацию транзакции, включая анимацию запроса.

Версия 0.1.40, сборка 41. Содержит остальные изменения 0.1.39.

## Подсветка папок и перенос задач

- Цвет названия и значка выбранной папки определяется внутри строки по системному `backgroundProminence`. Убран отдельный общий фокус панели из расчёта цвета, а смена оформления выполняется без анимации.
- Открытая папка в фокусе — фиолетовая с белым содержимым; без фокуса — серая с фиолетовыми названием и значком. Обычные строки используют системный основной цвет.
- При начале переноса настоящий клавиатурный фокус передаётся исходному списку задач без выбора переносимой задачи. Открытая папка становится серой ещё до наведения на другую папку.
- Назначение переноса отдельно подсвечивается фиолетовым с белым содержимым. Наведение не меняет открытую папку, карточку или список задач. Папка, которой задача уже принадлежит, остаётся серой; перенос в неё ничего не меняет, в том числе из «Сегодня» и «Всех задач».
- Временный контекст хранит только идентификаторы жеста и задачи с её основной папкой. Он не сохраняется в SwiftData. Подсветка убирается при выходе мыши и окончании жеста; контекст очищается при завершении, отмене и отпускании вне приложения. Запоздалое завершение предыдущего жеста не сбрасывает новый.
- Размеры строк, отступы и анимации вставки/удаления задач сохранены. Автоматического возврата фокуса в папки нет.

Добавлены регрессионные исходники для контекста переноса, собственного назначения, устаревших обработчиков, завершения вне назначения и нативной передачи фокуса без смены выбора. UI-сценарии проверяют перенос невыбранной задачи, перенос в её текущую папку и отпускание над документом. Визуальная проверка обоих цветов и отсутствия задержки остаётся за пользователем, включая обе темы, полноэкранный режим, поиск, Escape и быстрое переключение папок.

Проверка: приложение и тестовые исходники успешно собраны командой `build-for-testing`; тесты и экранная проверка не запускались. Проверено чтение настройки уменьшения движения через AppKit. Плавность в установленной версии проверяет пользователь. Универсальная Release-сборка и DMG проверяются штатным скриптом упаковки: архитектуры, локализация, иконка, права, подпись и содержимое смонтированного образа.

## English

Version 0.1.40, build 41. Fixes task-list update configuration after abrupt insertions and removals were reported in 0.1.39. The SwiftData query now supplies the animation transaction. Avoids forced scrolling to an already-visible new row or to the automatically selected neighbor after deletion. Honors Reduce Motion. App and test sources compile successfully; runtime animations are left for user verification. Universal ad-hoc signed macOS build.

Folder foregrounds now resolve from each row’s native background prominence, without a separate sidebar-focus color transition. Starting a task drag focuses the source list without changing the open task. The open folder keeps its gray, unfocused selection with purple contents; valid drop destinations are purple with white contents. A task’s existing folder stays gray and accepts a no-op drop, including from Today and All Tasks. Temporary drag state is cleared after completion, cancellation or release outside the app. Navigation, storage and task insertion/deletion animations are preserved. Regression sources are compiled without running the app or tests; no GitHub release is published.
