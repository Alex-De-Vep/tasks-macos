# Задачи 0.1.42 / Tasks 0.1.42

Предварительный выпуск **0.1.42, сборка 43**. Ниже собраны все изменения с опубликованной версии 0.1.32.

## Папки и перенос задач

- У каждой задачи теперь одна основная папка: «Входящие», «На неделе», «Месяц» или пользовательская. Новая задача создаётся в открытой папке.
- «На неделе» и «Месяц» стали постоянными папками: смена даты больше не перемещает задачи между разделами.
- «Сегодня» собирает отмеченные звёздочкой задачи, сохраняя их в основных папках. Во «Всех задачах» видна вся библиотека, новые задачи сверху. Создание из этих двух общих разделов помещает задачу во «Входящие»; в «Сегодня» дополнительно ставится звезда.
- Перенос доступен мышью на папку слева, через контекстное меню строки и меню «…» в шапке задачи. Перетаскивание на «Сегодня» добавляет звезду без смены папки.
- Назначение переноса подсвечивается фиолетовым с белыми значком и текстом. Открытая папка без фокуса остаётся серой с фиолетовым содержимым. Наведение не переключает папки и не открывает другую задачу; отмена переноса убирает временную подсветку.
- Счётчик над списком учитывает только активные задачи, включая текущий поиск.

## Выбор, редактирование и удаление

- Исправлена область нажатия: задачу можно открыть по тексту, свободному месту и внутренним отступам строки. Кнопки звезды и выполнения работают отдельно.
- Открытая задача остаётся выбранной при переходе к её названию или описанию. Исправлены потеря выделения и повторные клики без результата.
- Название, описание и подзадачи доступны для редактирования у сохранённых и выполненных задач. Исправлено повторное подключение нативного текстового редактора; сохраняются курсор, выделение текста и Undo/Redo.
- Смена папки закрывает карточку задачи и сворачивает выполненные. Пустая папка больше не открывает первую выполненную задачу автоматически.
- Delete в списке удаляет задачу без подтверждения. Если удалена открытая задача, выбор очищается и карточка закрывается; соседняя задача сама не открывается. В текстовых полях Delete продолжает удалять текст.

## Плавность интерфейса

- Исправлены резкие вставки и удаления строк: оставшиеся задачи плавно занимают новое положение, без мелькания конечного кадра и наложения текста.
- Первая задача в пустом списке сразу выделяется серым, а курсор переходит в название. Убраны краткая фиолетовая вспышка и повторное исчезновение первой строки.
- Звёзды «Сегодня» жёлтые, незаполненные значки читаются в обеих темах. Звезда и переименование не меняют порядок задач по дате создания.
- Учитывается системная настройка «Уменьшение движения». Обычный выбор и переход между папками не анимируются как вставка или удаление задач.

## Обновление существующей библиотеки

При первом запуске выполняется миграция SwiftData V4 → V5. Пользовательские папки сохраняются. Если своей папки нет, прежняя отметка недели или месяца определяет новую постоянную папку; остальные задачи остаются во «Входящих». Сохраняются идентификаторы, названия, описания, подзадачи, даты, звёзды, выполнение, сроки и связи с календарём.

## Установка и проверка

- **macOS 26 или новее**, универсальная сборка для **Apple Silicon и Intel**.
- Скачайте `Tasks-0.1.42-macOS-universal.dmg`, завершите предыдущую версию и замените приложение в «Программах». Sandbox-контейнер с библиотекой удалять не нужно.
- Сборка подписана локально **ad-hoc**, без Developer ID и нотариализации Apple. На другом Mac система может ограничить открытие загруженного приложения; исходники можно собрать в Xcode.
- Для проверки загрузки поместите DMG и файл SHA-256 в одну папку и выполните:

```sh
shasum -a 256 -c Tasks-0.1.42-macOS-universal.dmg.sha256
```

Успешно выполнены **32 регрессионные проверки в пяти наборах**: анимация настоящего NSTableView, первая строка в пустом списке, выбор и навигация, подключение редактора и контекст переноса. Приложение и тестовые исходники собраны. Создание, удаление, передача фокуса и выбор проверены в изолированной сборке с вымышленными данными; записи переходов разобраны по кадрам. Полный набор UI-тестов не запускался.

При упаковке проверены архитектуры, имя, иконка, локализация, права, подпись, контрольная сумма и содержимое смонтированного DMG.

## English

Preview **0.1.42, build 43**. This release includes all changes since published version 0.1.32.

- **Folders:** each task has one primary folder. This Week and Month are now permanent folders; Today mirrors starred tasks, and All Tasks shows the whole library ordered by creation date. New tasks belong to the open folder. Header counts include active search results only.
- **Moving tasks:** drag onto sidebar folders or use “Move to Folder” in the context or toolbar menu. Dropping onto Today adds a star without moving the task. Drop feedback no longer switches the open folder or task.
- **Selection and editing:** the whole row surface opens the task; star and completion buttons remain independent. The open task stays selected while editing. Native editor reattachment preserves text selection, cursor and Undo/Redo, including saved and completed tasks.
- **Navigation and deletion:** switching folders clears the open task and collapses completed tasks. Delete in the list removes a task without confirmation. Deleting the open task closes its editor and does not automatically open a neighbor. Delete inside text fields still edits text.
- **Animations:** fixed abrupt insertions/removals, end-state flashes and overlapping text. The first task in an empty list immediately uses gray selection, with focus in its title. Other list transitions remain animated and respect Reduce Motion. Stars and renaming preserve creation order.
- **Migration:** V4 → V5 preserves task contents and custom folders, otherwise converts old week/month markers into permanent folders. Existing task identifiers, dates, deadlines and calendar links are preserved.

Requires **macOS 26+**. Universal **Apple Silicon + Intel** DMG. Uses an **ad-hoc signature**, without Developer ID or Apple notarization. Quit the previous version before replacing the app; keep its sandbox container to preserve the task library.

**Verification:** 32 regression tests passed across five suites. App and test sources compile. Runtime interaction and frame-by-frame animation checks used an isolated in-memory app with fictional data. The full UI-test suite was not run. Packaging verifies both architectures, icon, localization, entitlements, signature, SHA-256 and mounted DMG contents.
