# Задачи 0.1.32 / Tasks 0.1.32 — Public Preview

Первый публичный выпуск нативного планировщика под Apache 2.0: папки, «Сегодня», планирование на неделю и месяц, описания, подзадачи и системный календарь с расписанием на день, три дня и неделю.

- Системные уведомления о сроках задач. Изменение срока заменяет прежнее уведомление; выполнение, удаление задачи или снятие срока отменяет его. Повторное открытие незавершённой задачи восстанавливает уведомление о будущем сроке.
- Для сроков без времени можно выбрать час уведомления, по умолчанию 09:00. Их день и час следуют за местным временем; срок с указанным временем сохраняет конкретный момент.
- Напоминание «Пора проверить задачи» настраивается отдельно: выключено по умолчанию, ежедневно или по будням, в выбранное местное время.
- Настройки разрешения, повторная попытка при ошибке планирования и тестовое уведомление через 5 секунд.
- Календарная форма показывает все напоминания, включая напоминания на конкретную дату. Можно изменять, добавлять и удалять отдельные строки. Неизменённые особые действия сохраняются; конфликт с внешним изменением напоминаний выдаёт ошибку перед записью.

- Новая фиолетовая иконка в нативной композиции macOS 26 без внешней белой подложки.
- Исправлен расчёт высоты многострочного редактора: описание не накладывается на подзадачи при переносах строк.
- [Описание всех настроек](../settings.md), документация RU/EN и скриншоты на вымышленных данных.

**Предыдущие проверки уведомлений по сохранённым журналам:** 37 целевых тестов уведомлений, календарных напоминаний, сроков и переноса событий; 4 проверки переводов; 2 UI-сценария настроек и календарной формы. При подготовке этого выпуска приложение и все тестовые исходники повторно скомпилированы без выполнения тестов. В автоматических UI-проверках системный центр заменён тестовым: фактический баннер и разрешение macOS проверяются кнопкой «Проверить уведомление» в установленном приложении. Календарные проверки используют отдельное хранилище и реальные EKAlarm без доступа к личным календарям.

**Доставка:** нужна разрешённая отправка уведомлений в macOS; «Фокусирование» и другие системные настройки влияют на показ. Приложение планирует все будущие сроки. Если системный центр ограничивает очередь и не сохраняет часть запросов, приоритет получают ближайшие сроки и повторяющиеся напоминания; остальные добавляются при запуске, возвращении в приложение или изменении задач. Настройки показывают сообщение, если часть сроков ожидает следующего обновления очереди. Прошедшие сроки не создают новые уведомления задним числом. Доставленные ранее сообщения убираются при выполнении, удалении или изменении соответствующей задачи.

Сборка универсальная для Apple Silicon и Intel, macOS 26+. Локальная ad-hoc подпись, без Developer ID и нотариализации. Прежняя библиотека и идентификатор приложения сохраняются.

DMG смонтирован только для чтения и проверен: обе архитектуры, подпись, разрешения, имена, иконка и LICENSE/NOTICE. В Release нет демонстрационных данных. Файл SHA-256 приложен для проверки целостности. На другом Mac Gatekeeper может ограничить запуск загруженного пакета; исходники доступны для сборки в Xcode.

## English

First public preview of a native macOS planner under Apache 2.0, including folders, subtasks and system calendar integration. Includes a native purple app icon without an outer white tile and a fix for descriptions overlapping subtasks. Task deadlines now schedule local notifications, reschedule after edits and cancel after completion, deletion or deadline removal. Date-only deadlines use a configurable local hour; timed deadlines preserve the due instant. A separate daily or weekday review reminder is off by default. Settings include permission status, retry and a test notification. Calendar alerts now support multiple entries and absolute dates while preserving untouched alerts and detecting concurrent changes.

Previous verification logs report 37 targeted unit tests, 4 localization tests and 2 UI scenarios passing. For this release, the app and all test sources were compiled again without executing tests. Automated UI tests use a substitute notification center; verify native delivery with “Test notification” in the installed app. The scheduler submits all future deadlines. If the system limits pending requests, it prioritizes the nearest deadlines and repeating reminders and refills on launch, activation and task changes. macOS notification permission and presentation settings apply. Universal ad-hoc signed build for macOS 26+, without Apple notarization.
