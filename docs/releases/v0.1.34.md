# Задачи 0.1.34 / Tasks 0.1.34

- Переход в другую папку сбрасывает открытую задачу и сворачивает «Выполнено» одной транзакцией.
- Папка без активных задач больше не открывает первую выполненную задачу автоматически. То же правило действует при повторном возвращении в папку.
- Повторное нажатие на текущую папку сохраняет открытую задачу. Создание задачи, переход по календарной ссылке и открытие из уведомления продолжают выбирать конкретную задачу.
- Открытую задачу по-прежнему можно выполнить, сохранив её на экране. Схема хранения не меняется.

Добавлены регрессионные проверки навигации и пользовательского пути со сворачиванием выполненных. Приложение и тестовые исходники собираются без запуска приложения и тестов; интерфейс проверяет пользователь.

Универсальная локальная сборка: Apple Silicon и Intel, macOS 26+. Подпись ad-hoc, без Developer ID и нотариализации.

## English

Switching folders now clears the open task and collapses completed tasks together. Folders containing only completed tasks no longer automatically open one of them, including when returning to a folder. Selecting the current folder again preserves the open task. Task creation, calendar links and notification links still open a specific task. Storage schema is unchanged.

Navigation and UI regression checks are included for compilation without running the app or tests. The universal local build uses an ad-hoc signature and is not notarized.
