# Задачи 0.1.31 / Tasks 0.1.31 — Public Preview

Первый открытый выпуск нативного планировщика для macOS. Исходники опубликованы под Apache 2.0.

- Папки, «Сегодня», планирование на неделю и месяц, сроки и локальные уведомления.
- Название, многострочное описание и подзадачи. Исправлено наложение описания на блок подзадач при переносах строк.
- Панель системного календаря: день, три дня и неделя, создание и изменение разовых событий, связь событий с задачами.
- Локальная библиотека SwiftData, светлая и тёмная темы, русский и английский интерфейс.

**Установка:** скачайте DMG, перетащите «Задачи» в Applications и извлеките образ. Нужна **macOS 26 или новее**, поддерживаются Apple Silicon и Intel.

**Подпись:** эта предварительная сборка подписана ad-hoc, без Developer ID и нотариализации Apple. macOS может заблокировать обычный запуск загруженного приложения. Исходники доступны для самостоятельной сборки в Xcode; подписанный и нотариализованный выпуск пока не предоставляется.

**Ограничения:** задачи хранятся локально, синхронизации библиотеки между устройствами нет. Описание — обычный текст. Повторяющиеся и недоступные для записи календарные события открываются только для просмотра. Системные календарные учётные записи могут синхронизировать события через своих провайдеров.

**Проверка выпуска:** приложение и тестовые исходники собраны без выполнения тестов. Интерфейс редактора просмотрен на отдельных демонстрационных данных; доступ к личным календарям для проверки не запрашивался. DMG проверен и смонтирован только для чтения, проверены обе архитектуры, иконка, имена, права и локальная подпись. Демонстрационный режим в Release не включён.

Рядом с DMG находится SHA-256. Скачайте оба файла в одну папку и выполните:

```sh
shasum -a 256 -c Задачи-0.1.31-macOS-universal.dmg.sha256
```

---

First public preview of a native macOS task planner, licensed under Apache 2.0.

- Folders, Today, week/month planning, deadlines and local notifications.
- Plain-text descriptions and subtasks; fixed text overlapping the subtask section when wrapping.
- System calendar integration with day, three-day and week views, editable one-off events and task links.
- Local SwiftData storage, light/dark appearance, Russian and English.

Requires **macOS 26+**, Apple Silicon or Intel. Open the DMG and drag the app to Applications.

This build is **ad-hoc signed, without Developer ID or Apple notarization**. macOS may block normal launch of the downloaded application. You can also build from source in Xcode.

Tasks are stored locally; device-to-device task sync is not provided. Recurring and read-only events cannot be edited. Connected calendar providers may sync events independently. App and test sources were compiled; tests were not executed. Screenshots use fictional in-memory data. The release excludes the showcase mode. A SHA-256 file accompanies the DMG.
