# Задачи 0.1.41 / Tasks 0.1.41

Версия 0.1.41, сборка 42. Содержит изменения 0.1.40 и исправляет реально воспроизведённое отсутствие анимации списка.

- Колонка задач получает обновления через постоянный SwiftUI-корень с передачей транзакции из AppKit-оболочки.
- У текущей версии нативного List одного `withAnimation` оказалось недостаточно: измерение показало мгновенное изменение положения на 70 pt. Теперь вставка и удаление используют короткий переход нативных слоёв длительностью 0,26 секунды. Системные List, выделение, кнопки, клавиатура и перенос сохранены.
- Перед изменением результатов фиксируется текущий вид видимых строк. Конечная геометрия не мелькает перед началом перехода. При повторном действии учитывается текущее положение незавершённой анимации.
- При вставке сначала освобождается место, затем появляется новая строка. При удалении сначала исчезает удалённая строка, затем остальные занимают её место. Растровый кадр удалённой строки не обращается к уже удалённой модели SwiftData.
- Поиск, переход между папками и обычная смена выбора не запускают анимацию вставки/удаления. Системное уменьшение движения отключает переходы.
- Удаление открытой задачи очищает выбор и закрывает карточку. Соседняя задача автоматически не открывается, выполненные не раскрываются. При ошибке сохранения удаляемая задача остаётся открытой. Удаление другой задачи сохраняет открытую карточку.
- Схема данных, правила папок и порядок задач не меняются.

## Проверка

По отдельному разрешению пользователя приложение и тесты запускались. Проверочная сборка использует SHOWCASE, отдельный bundle ID, задачи и календарь в памяти. Проверены реальные создание и Delete, пустой выбор после удаления, повторный выбор кликом и стрелкой, переход между папками. Запись экрана разобрана по кадрам: видны промежуточные положения строк; исправлено мелькание конечного кадра и наложение текста в начале перехода.

Успешно выполнены 29 проверок в пяти наборах. Автоматические проверки измеряют промежуточные положения настоящего NSTableView, в том числе при повторной вставке до окончания первого перехода. Проверки выбора, редактора и контекста переноса запускаются на изолированных данных. UI-тестовые исходники дополнены правилом удаления без автоматического открытия соседней задачи.

Универсальная сборка для Apple Silicon и Intel упакована штатным скриптом: проверяются имя, иконка, локализация, права, ad-hoc подпись, архитектуры, контрольная сумма и содержимое DMG. GitHub-релиз не публикуется.

## English

Version 0.1.41, build 42. Preserves 0.1.40 changes. Reproduced and fixed missing task-list transitions using native row presentation animations, while keeping SwiftUI List selection and interactions. Insertions make room before revealing the new row; deletions fade the outgoing row before closing the gap. A stable hosted SwiftUI root and a temporary presentation snapshot prevent an end-state flash. Reduce Motion disables these transitions.

Deleting the open task now clears selection and closes its editor without opening a neighbor. Explicit clicks and arrow-key navigation still work. Storage and task ordering are unchanged. Runtime checks used an isolated in-memory showcase app, frame-by-frame screen recordings and native-table regression tests. Local universal ad-hoc signed DMG only; no GitHub release is published.
