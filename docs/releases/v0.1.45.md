# Задачи 0.1.45 / Tasks 0.1.45

Локальная предварительная сборка **0.1.45, сборка 46**. Включает [изменения 0.1.44](v0.1.44.md).

## Редактирование подзадач

- Исправлен скачок курсора в конец при наборе текста в середине подзадачи. Для каждого пункта используется собственный нативный редактор, сохраняемый между обновлениями карточки. При сохранении символа текст не присваивается редактору повторно, если уже совпадает с моделью.
- Сохраняются перенос текста, автоматическая высота без ограничения строк, оформление выполненных пунктов, создание следующего пункта через Enter и работа нижней кнопки добавления.
- При внешнем обновлении текста сохраняется допустимый диапазон выделения. Удаление пункта или основной задачи освобождает соответствующие сохранённые редакторы.

## Проверка

Контрольный UI-прогон подтвердил ошибку прежнего многострочного поля: первый символ вставлялся в середину, следующий уходил в конец. Тот же сценарий прошёл с новым редактором. Подготовка теста использует навигационные клавиши, не зависящие от раскладки.

Успешно выполнены **14 целевых проверок**:

- **4 UI-теста:** ввод по одному символу в середине короткого и многострочного пункта; повторное создание подзадач нижней кнопкой; полный длинный текст, Enter, перезапуск, выполнение и удаление пункта.
- **10 проверок редактора и хранения:** независимые редакторы пунктов, сохранение выделения при повторном подключении, переносы без изменения текста или курсора при измерении высоты, очистка кэша нужной задачи, прежние сценарии подключения основного редактора, порядок, миграция, сохранение и каскадное удаление подзадач.

Приложение запускалось с отдельным Bundle ID, вымышленными данными в отдельной библиотеке и подменой календаря. Полный набор тестов не запускался. Общая схема по-прежнему отключает UI-тесты по умолчанию.
