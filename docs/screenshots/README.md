# Скриншоты приложения

Снимки сделаны с работающего приложения, а не с макета. Все задачи, папки, подзадачи и события вымышленные. Личные данные и системные календари при подготовке не используются.

- `workspace-light-ru.png` — русский интерфейс, светлая тема.
- `workspace-dark-ru.png` — русский интерфейс, тёмная тема.
- `workspace-light-en.png` — английский интерфейс, светлая тема.
- `settings-ru.png` — настройки языка, уведомлений и календарей с включённым для демонстрации ежедневным напоминанием.

Воспроизведение: `python3 scripts/prepare_showcase.py`, затем открыть нужное приложение из `.build/showcase/` и выбрать первую задачу. Скрипт не запускает приложение и не делает снимки сам. Подробнее — [руководство разработчика](../development.md#скриншоты).
