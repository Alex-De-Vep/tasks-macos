# Иконка «Задачи»

С версии 0.1.32 используется выбранная пользователем фиолетовая иконка с двумя строками контрольного списка. Изображение создано встроенным imagegen 27 октября 2026 года; `tasks-icon.png` — сохранённый PNG с прозрачностью без внешней белой подложки.

`scripts/prepare_app_icon.py` воспроизводит стандартные размеры в `Planner/Assets.xcassets/AppIcon.appiconset` и нативную композицию `Planner/TasksIcon.icon` с исходным PNG, фиолетовым фоном и масштабом 1.27. Эту композицию компилирует Xcode для macOS 26; маску скругления применяет система.

Композиция устраняет дополнительную белую плитку, которую macOS показывала вокруг прежнего растрового значка. Исходное изображение не ретушируется. `tasks-icon-preview.png` — экспорт композиции средствами Apple для README.

Предыдущие исходники находятся в `archive/0.1.30` и `archive/0.1.31`.

Промпт генерации: одна фиолетовая скруглённая плитка на прозрачном фоне, без внешней белой или серой рамки; сверху белая галочка и короткая линия, снизу белый контур круга и короткая линия. Ровная толщина, точное выравнивание, мягкий фиолетовый градиент, без текста и дополнительных элементов.
